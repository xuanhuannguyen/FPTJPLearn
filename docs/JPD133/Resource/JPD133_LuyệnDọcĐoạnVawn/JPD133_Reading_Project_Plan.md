# 1. Mục tiêu

Xây dựng bộ Reading hoàn chỉnh cho JPD133 nhằm:

-   Luyện đọc hiểu N5
-   Luyện Kanji
-   Luyện từ vựng
-   Luyện ngữ pháp
-   Luyện Speaking Reading
-   Có thể chuyển trực tiếp sang JSON của project
